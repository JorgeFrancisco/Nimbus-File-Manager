# Contributing

Thank you for considering a contribution to Nimbus File Manager.

Nimbus File Manager uses a source-available license and is also offered under
separate commercial terms. To preserve that licensing model, external
contributions can be accepted only after the contributor signs a separate
contributor agreement that permits both public noncommercial and commercial
licensing.

Please contact the project owner before preparing a pull request. Do not submit
code or other material that you do not have the right to license.
